# ADR-0003: 火山引擎部署决策

| 字段 | 值 |
|------|-----|
| 编号 | 0003 |
| 标题 | 火山引擎部署决策 |
| 状态 | Accepted |
| 日期 | 2026-07-03 |
| 决策者 | 项目团队 |

## 上下文

RiskMonitor-FrontEnd 需要部署到云厂商，与后端 RiskMonitor-MultiAgent 打通并提供公网访问。部署方案需满足以下约束：

1. **支付便利**：支持支付宝付款
2. **中国访问**：中国用户可直接访问，无需翻墙
3. **低延迟**：与后端 LLM 服务（火山引擎方舟 ark-code-latest）网络延迟最低
4. **简单便宜**：部署和运维成本低，MVP 阶段不过度设计

备选方案包括：

- Vercel（前端）+ 国际 VPS（后端）：Vercel 在中国被 DNS 污染，且不支持支付宝
- 阿里云 / 腾讯云：国内云，支持支付宝，但与方舟 LLM 不在同一云
- 火山引擎 ECS 单台部署：同云内网，支持支付宝，最简单

## 决策

选择 **火山引擎单台 ECS 一体化部署**方案：

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 云厂商 | 火山引擎 | LLM 同云内网延迟最低，支持支付宝 |
| 部署架构 | 单台 ECS + nginx | 前后端同源，无 CORS 问题，最简单 |
| 实时通信 | 轮询（非 SSE） | MVP 阶段最简单可靠，无超时问题 |
| 前端托管 | nginx 静态文件 | 无需额外服务，与后端同台 |
| 域名 | 暂用 IP | MVP 阶段省域名费用，后续升级 |

### 架构

```
用户浏览器 → 火山引擎 ECS (nginx :80)
  ├── /      → 前端静态文件
  ├── /api/* → proxy → MCP Server (:8000)
  └── /health→ proxy → MCP Server (:8000)
```

## 理由

### 选择火山引擎而非 Vercel + 国际 VPS

- Vercel 的 `*.vercel.app` 域名在中国大陆被 DNS 污染，基本无法直接访问
- Vercel 仅支持信用卡付款，不支持支付宝
- 火山引擎与方舟 LLM 同云，内网调用延迟最低
- 火山引擎支持支付宝付款

### 选择单台 ECS 而非前后端分离部署

- 前后端同源部署，nginx 统一代理，无需配置 CORS
- 一台服务器一个账单，运维最简单
- MVP 阶段流量低，单台 2C4G 足够
- 后续可随时拆分为前后端分离部署

### 选择轮询而非 SSE

- SSE 在 Vercel 等平台有超时限制（25-60 秒），需额外处理
- 轮询实现最简单，前端定时 GET 请求即可
- MVP 阶段对实时性要求不高，2 秒轮询间隔足够
- 后续可升级为 SSE，后端已有 MessageBus 内部事件机制可桥接

## 后果

### 优势

- 部署简单：一台服务器，docker-compose + nginx 即可
- 成本低：约 ¥60-100/月，支持支付宝
- 无跨域问题：同源部署，nginx 代理
- 低延迟：与方舟 LLM 同云内网
- 中国用户直接访问：无需域名和 CDN

### 风险

- 单点故障：单台 ECS 无高可用，宕机即全站不可用
- 无 HTTPS：MVP 阶段用 HTTP，后续需加域名 + Let's Encrypt
- 带宽受限：5Mbps 带宽在高并发时可能成为瓶颈
- 无自动部署：前端更新需手动 SSH 构建部署

### 缓解措施

- MVP 阶段可接受单点风险，后续可升级为多实例 + 负载均衡
- 后续添加域名 + Let's Encrypt 免费 SSL 证书
- 带宽可随时升级，或迁移前端到 TOS + CDN
- 后续可通过 GitHub Actions 实现自动构建部署
